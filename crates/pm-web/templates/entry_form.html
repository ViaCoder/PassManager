基本信息

留空时按第一个域名自动生成。

  • 可以写主机名，也可以直接粘贴 https 网址（只取主机和端口）；端口不用写，除非要限定；
  • *.example.com 匹配所有子域名，但不含 example.com 本身；
  • 网段如 198.51.100.0/24 只匹配直接用 IP 访问的目标；可写 host:端口；
  • 多个条目都匹配时用最具体的；留空则保存为"未绑定域名"，Agent 暂时不能使用。
  • 填写后 Agent 只能写 alias://别名/路径：真实地址由服务器代入，并从返回给 Agent 的结果里去掉。清空即恢复。
  • 这台主机的所有端口和用途都不能再被 Agent 直接访问，包括 SSH。条目要绑定一个具体主机，并勾选 HTTP。
  • 做不到的：同一台服务器的其他域名或 IP 不受保护；Agent 如果在能访问它的机器上有 shell，可以自己拼出地址。
